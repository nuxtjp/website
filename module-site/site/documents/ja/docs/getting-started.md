## アプリを作成する

Node.jsとパッケージマネージャーを用意し、Nuxt公式の作成コマンドを実行します。

```
npm create nuxt@latest
```

## 開発サーバーを起動する

作成したアプリのディレクトリで実行します。

```
npm run dev -- -o
```
