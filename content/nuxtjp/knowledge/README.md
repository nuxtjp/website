# Historical NuxtJP knowledge

The Markdown and favicon in this directory are preserved byte for byte from the
retired application. `source-provenance.json` records each original path, commit
and SHA256. Existing copyright, license and brand terms remain unchanged; this
move grants no new license.

These are historical materials, including the former Vuetify playground syntax.
They are not loaded as application components or added to the published page
manifest. Current bilingual MDC pages are maintained in `module-site/site/`.
The retired Vue application, dependencies and CI build are retained in Git history.
